## Cómo abrir el juego

1. Descarga `PASAMANOS_PEDRO_MIGUEL.zip` desde el enlace de arriba.
2. En Windows, haz clic derecho sobre el ZIP y elige **Extraer todo**.
3. Abre la carpeta extraída.
4. Haz doble clic en `PASAMANOS_PEDRO_MIGUEL.html`. Si Windows pregunta con qué abrirlo, elige **Microsoft Edge** o **Google Chrome**.
5. Espera a que termine de cargar el contenido antes de empezar.

El ZIP ocupa aproximadamente 112 MB y el HTML extraído, 171 MB. Contiene modelos e imágenes incrustados y puede tardar en abrir según el equipo. No requiere un instalador EXE. No se ha verificado el funcionamiento completo sin conexión.
